# Google Dinosaur

一个可直接在浏览器中运行的 Chrome 离线小恐龙游戏复刻版。

这个仓库面向普通使用者：下载后无需安装依赖，也不需要构建步骤，只要启动一个静态文件服务就能游玩。

## 立即开始

1. 下载或克隆仓库。
2. 在仓库根目录启动一个静态文件服务。
3. 用浏览器打开对应地址，进入游戏。

如果你的电脑装了 Python，可以在根目录执行：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

如果你使用 Node.js，也可以执行：

```bash
npx serve .
```

## 游戏操作

- `空格` / `↑` / `W`：开始游戏、跳跃
- `↓` / `S`：下蹲
- `Enter`：游戏结束后重新开始
- 触屏或鼠标点击画面：开始游戏、跳跃
- 在触屏设备中按住画面下方区域：下蹲

## 仓库内容说明

- `index.html`：页面入口
- `styles.css`：页面布局与画布显示样式
- `src/`：游戏逻辑、输入、音效与存档代码
- `assets/`：当前项目实际使用的图片与音频资源

## 当前项目特点

- 使用原生 JavaScript 与 Canvas 2D 渲染
- 支持键盘、鼠标、触控操作
- 浏览器本地保存最高分
- 已内置精灵图与音效资源，开箱即玩
- 开始前页面保持正常显示，开始后保持完整游戏流程

## 常见问题

### 为什么建议使用静态文件服务，而不是双击打开 `index.html`？

直接使用 `file://` 打开页面时，部分浏览器对资源加载、音频播放和本地存储的处理会不一致。通过本地静态服务打开最稳定。

### 游戏资源在哪里？

当前实际资源位于 `assets/images/` 和 `assets/sounds/`。

### 最高分会保存在哪里？

最高分会保存在浏览器本地的 `localStorage` 中，只保存在你自己的设备里。
